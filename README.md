# GAPIAN

Premium creator intelligence dashboard built with React, Vite, and Tailwind CSS.

## Features

- Executive dark dashboard layout
- Responsive two-column interface
- AI idea generation placeholder service
- Clean reusable component structure
- Tailwind CSS theming and typography
- Future-ready environment variable placeholders

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Environment

Copy `.env.example` to `.env` and provide your API key for future integration.

```env
VITE_GEMINI_API_KEY=
VITE_API_BASE_URL=
VITE_BACKEND_URL=
```
